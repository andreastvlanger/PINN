
# An Implementation of AD-PINNs and FD-PINNs

## Overview

This repository contains implementations of physics-informed neural networks (PINNs) based on automatic differentiation (AD-PINNs) and finite differences (FD-PINNs), and was used to generate the numerical experiments presented in the paper

[1] Andreas Langer. 'The ill-posed foundations of physics-informed neural networks and their finite difference variants'. arXiv preprint arXiv:2601.07017, 2026. [link](https://arxiv.org/abs/2601.07017)
                                             
Read and use at your own risk.

If you use this code, please make sure to cite [1].
